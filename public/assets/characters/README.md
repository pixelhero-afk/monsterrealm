# Monster Character Assets

This directory contains the canonical character assets for Monster Realms, organized by monster family and element.

## Directory Structure
```
public/assets/characters/[family]/[element]/
```

### Families
- boss
- floraweaver
- freedancer
- luminary
- nekohime
- pyrosaur
- shadowstalker
- tideguard

### Elements
- dark
- fire
- grass
- light
- water

### Standard File Names
Each [family]/[element] folder expects the following PNG files:
- **PORTRAIT.png** - Square monster portrait icon (Codex, Party, Summon, UI)
- **IDLE.png** - Combat idle stance
- **ATTACK.png** - Combat attacking frame
- **HURT.png** - Combat damaged state
- **DEAD.png** - Combat defeated state
- **VICTORY.png** - Combat victory pose
